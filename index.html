    Minimum Underpinning Theory: JavaScript Dark & Light Mode

    Event-driven DOM class/attribute toggling, window.matchMedia(), and localStorage persistence.

    Implementing Dark Mode in a web application using JavaScript combines event-driven programming, DOM manipulation, and local data persistence. Clicking the theme switch toggles a data-theme="dark" / data-theme="light" attribute on the root <html> element to swap CSS custom properties instantaneously. Additionally, querying window.matchMedia('(prefers-color-scheme: dark)') detects the user’s operating system theme preference, while localStorage preserves the chosen mode across page reloads and sessions.
